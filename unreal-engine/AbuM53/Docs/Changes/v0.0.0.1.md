# v0.0.0.1 — Initial Git Baseline, Walkthrough and Versioning

Date: 2026-10-25. Status: development baseline.

## Request and purpose

Document the previous Abu M53 work in Markdown, introduce real local Git version control, and begin at `v0.0.0.1` using decimal carry (`v0.0.0.9` → `v0.0.1.0`).

## Steps performed

1. Inspected the plugin folder and confirmed it had no existing Git repository or history. Used the user's existing Git identity rather than inventing an author.
2. Wrote [the implementation and validation walkthrough](../Abu_M53_Implementation_and_Validation_Walkthrough.md), reconstructing the prior work from source and saved evidence.
3. Established the authoritative `VERSION` file and aligned the plugin descriptor, CMake metadata and current documentation labels.
4. Added the documented change workflow, repository-level agent instructions, changelog and this first change record.
5. Added a version helper and tests covering carry boundaries, invalid versions, metadata synchronization and release records. Added those checks to CI.
6. Preserved exact file bytes across Git checkouts with `.gitattributes` to protect fixture contents and audited dependency hashes. Updated the source audit to permit these intentional repository files while retaining exclusions for binaries, generated output and private data.
7. Checked version consistency, helper behavior, source inventory and Git whitespace. Recorded the full source and documentation in one initial commit and annotated it as `v0.0.0.1`.

## Files and areas

- New: `.gitattributes`, `VERSION`, `CHANGELOG.md`, `AGENTS.md`, the walkthrough, version-control workflow, this change record and `Tools/Versioning/`.
- Updated: `AbuM53.uplugin`, `Core/CMakeLists.txt`, README, CurrentScope, ImplementationStatus, source audit and portable CI workflow.
- Existing source, shaders, fixtures, licenses and compact evidence enter Git as the baseline; this does not mean they were all newly written in this documentation change.

## Validation and scope

Checks completed for this change: version consistency passed; all three version-helper tests passed; source audit passed with 116 files and no violations; all four source-package roundtrip checks passed. The first test attempt failed because the default Windows temporary folder was inaccessible; rerunning with TEMP/TMP and the package test work directory inside ignored `Intermediate/VersionTests` passed.

Run the commands in the workflow to reproduce the version/helper/source checks. Those are historical implementation results, not newly rerun tests of this metadata/documentation change.

Git whitespace review: configured this repository to recognize CRLF line endings. The full initial baseline retains existing warnings in `Core/Source/Core.cpp` (blank EOF), `Docs/ImplementationPlan.md` (Markdown hard-break spaces and blank EOF), and `LICENSE` (indentation). Newly added or edited versioning/documentation files pass the scoped whitespace check. Existing historical and license contents were preserved.

No runtime rendering or import algorithm changed here. Engine rebuilds and GPU benchmarks are not repeated solely for a version-label update. The existing `0.1.0-dev` ZIP remains unchanged; the new source release uses the requested numbering. Source packages exclude `.git`; the working repository retains the actual history and tags.

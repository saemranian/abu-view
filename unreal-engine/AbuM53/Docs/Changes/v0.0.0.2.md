# v0.0.0.2 — Engine Installation and Persistent UE 5.8 Test Project

Date: 2026-10-25 (UTC). Previous: v0.0.0.1.

## Request and result

Install Abu M53 in this PC's UE plugins, keep its installed version current after each completed edit, and create the persistent `abu_M53_Test_01` UE 5.8 project.

## Steps performed

1. Confirmed the installed engine is UE 5.8.2, CL 56702186. The original source repository remains the development authority.
2. Added a deployment workflow that snapshots audited source, runs Unreal BuildPlugin for Win64 editor/Development/Shipping targets, verifies required source and binaries, and installs under `Engine/Plugins/Marketplace/AbuM53`.
3. Added safe replacement and recovery: version/source checks, refusal of stale builds or changed same-version installs, module-lock checks, hash verification, and backups outside UE plugin discovery. Added documentation-only finalization for actual test results before a release is tagged; code/config/tool changes still require rebuilding.
4. The first BuildPlugin run compiled the editor but failed in standalone Development because renderer files depended on precompiled headers for RHI static-state declarations. Added explicit `RHIStaticStates.h` includes in AbuM53Render.cpp and AbuM53Tiles.cpp. No rendering algorithm changed.
5. The next build passed all three targets, but install validation caught the omitted FilterPlugin.ini. Added `/Config/...` to the package rules and rebuilt. The final build passed all targets and included the required portable sources, dependencies, configuration, fixtures and documentation.
6. Installed v0.0.0.2 into the UE 5.8 engine plugin directory and verified all 192 initial package files against their hashes. Subsequent documentation finalization adds the compact evidence record to that same untagged release and refreshes installed hashes.
7. Created `Documents/Unreal Projects/abu_M53_Test_01/abu_M53_Test_01.uproject`, associated with UE 5.8, using the engine-installed plugin. Python/editor scripting are enabled; unrelated Marketplace plugins are disabled for isolation. No project-local duplicate or additional search path was added.
8. Ran first-time setup in Unreal. Imported four original 1,000-splat fixtures, verified all four seek expectations for the three-frame sequence, and saved ShellQA (static) and AnimationQA (looping animation). The setup refuses to overwrite an initialized test project.
9. Ran the installed plugin's eight automation tests with DX12/SM6, including GPU scan and radix tests. All passed. Captured and inspected the static sample at 1280×720. An initial capture using ExecutePythonScript exited after four ticks; rerunning via the normal `py` console execution mode allowed the asynchronous screenshot to complete.
10. Updated release metadata, project instructions, CI, feature/setup documentation and this change record. Finalized documentation in the installed copy, verified its hashes, and committed/tagged the completed release. Every subsequent completed development edit must bump the version and refresh this PC's installation through the same documented workflow.

No new FPS or high-count performance claim is made. The version update workflow is explicit; it does not silently update modules inside a running editor or publish to GitHub.

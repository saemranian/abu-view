# Prepare a PLY animation sequence

Run `prepare_ply_sequence.py --source <folder> --output <new-folder-outside-Git> --fps 30` with Python 3. The tool creates `sequence.am53seq`, a `frames` directory and `sequence-preparation.json`. Frame names are naturally sorted. The FPS value is an explicit playback assumption because these PLY files contain no timing metadata.

All original Gaussian records, rotations, scales, opacity and SH coefficients are retained. This is an independent frame sequence with sample-and-hold playback. Equal point counts and matching row numbers do not prove stable identities; no interpolation is claimed. The tool accepts binary fixed-width Gaussian PLY files and checks file lengths and bounded samples. The full UE decoder remains responsible for complete scalar validation.

Copies are the default. `--hardlink` explicitly permits hard links on the same volume, with a copy fallback. Hard links save storage but share file contents: do not edit either linked frame. The tool never opens source files for writing and deliberately does not change their read-only attribute. Use an empty, new output directory. Private inputs and prepared outputs must stay outside Git.

Read `recommended_loading` and `recommended_streaming_cache_mib` in the report/manifest metadata. An embedded sequence shares the default 1 GiB decoded import budget across all frames. An external sequence index keeps frames on disk and decodes frames into a bounded cache. For the supplied three-frame Skate clip, every frame contains 3,000,000 SH3 splats: 744,001,532 source bytes and 768,000,000 decoded point bytes per frame. All three exceed the embedded import budget. A 3072 MiB cache accommodates all three frames while satisfying current/next/fallback reservations. Large prepared clips explicitly declare `storage: "external"` so importing the manifest through the Content Browser creates a persistent external-index asset. Drop that asset into a level and set the recommended streaming cache size. Smaller clips declare `storage: "embedded"`; they can also be loaded as external indices through the component's asynchronous file-loading API.

External frames must remain available at their prepared paths. They are not automatically included in a cooked game. Copy the complete prepared directory into a deliberate distribution location before producing a distributable external sequence; do not distribute private source data through the plugin repository.

Run `python -m unittest discover -s Tools/Sequences -p "test_*.py"` from the repository to check preparation safeguards. `Tools/QA/ue_sequence_validation.py` performs real UE loading, displayed-frame checks, render captures, seek/playback and map reload checks; its module docstring documents inputs and outputs.

The CPU decoded-frame cache and GPU source-buffer cache have separate budgets. The QA script uses `ABUM53_SEQUENCE_CACHE_MIB=3072` for CPU frames and `ABUM53_SOURCE_CACHE_MIB=3072` for retained GPU source buffers. GPU sorting and rasterization allocate additional memory. GPU caching avoids uploading the same retained frame again when a short clip loops. The warm-playback CSV reports actual uploads, cache hits and residency when the renderer exposes these counters; an older renderer is explicitly identified as a baseline without those counters.

Run the asynchronous QA script through `-ExecCmds="py <absolute-script-path>"`, not `-ExecutePythonScript`. It temporarily disables editor background CPU throttling for native animation ticks and restores that setting on completion. Captures and PNG analysis finish before the timed 10-second native-playback interval. CSV GPUTime describes the engine's aggregate GPU frame time; callback intervals describe editor wall time. Neither is presented FPS. Reverse warm seeks exercise frame reuse before profiling.

Run `python -m unittest discover -s Tools/QA -p "test_sequence_validation.py"` for CSV parser and lifecycle checks. These include an actual exclusive Windows writer handle, incomplete/changing files, missing instrumentation, renderer count mismatches, retained versus disabled GPU caches, budget violations and nested Slate callbacks during save/reload. The CSV poll waits for a stable file with UE's final metadata marker; temporary sharing violations remain pending until the bounded timeout expires. The script suspends callbacks while synchronously saving its known test map and replacing the editor world, then resumes only after the reloaded component is ready for validation.

PLY sequences do not provide a trained viewing camera. The default sampled-bounds view is a diagnostic view and can look through foreground floaters or the back of a reconstruction. Inspect captures and supply `ABUM53_SEQUENCE_CAMERA` as JSON containing source-space `location`, `target` and `fov` values. Colored pixels and correct frame counts alone do not establish visual fidelity. No source Gaussian is cropped or removed to make the QA result appear better.
